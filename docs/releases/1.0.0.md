# One Clipboard History 1.0.0

The first 1.0 GitHub release of the native Swift/AppKit clipboard history for
**macOS 27 on Apple Silicon**.

- Open history with a configurable shortcut (default ⌥A); paste with a digit,
  Return or double-click.
- Keep text, rich formats, images, file references and available private
  representations without replacing original bytes with previews.
- Choose Compact, Normal or Large density, 10–28 pt text, native light/dark
  appearance, fixed placement or opening beside the mouse pointer.
- Use English, French, Spanish, Italian, Russian, Simplified Chinese or German.
- Configure history length, data budget, optional persistence and silent login
  launch. Defaults remain 20 entries, 256 MiB and memory-only storage.
- Releases are now built and published by GitHub Actions from validated tags,
  with a verified app ZIP, SHA-256 checksum and source manifest.

Existing direct-installation preferences and history remain compatible through
`com.arthur.mcm`. The project and documentation use English.

## Known limits

Historical Excel copies can paste calculated values instead of formulas when
their original context cannot be reconstructed. A warning and explicit
confirmation protect affected entries; their raw formats are retained.
Automatic paste requires macOS permission. Physical focus/shortcut, complex
Office, VoiceOver and session/display scenarios still have qualification items
in the [validation report](https://github.com/armateurlabs/one-clipboard-history/blob/main/docs/VALIDATION.md).

This release does not claim Apple signing, notarization or App Store approval;
the package's signing status is reported below.
